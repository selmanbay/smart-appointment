# ADR-0006: English is the project language

- **Status:** Accepted
- **Date:** 2026-11-21
- **Feature:** general

## Context

The early planning notes mixed Turkish and English. Reports are written in English, and agents work more consistently when code, comments and documentation share one language.

## Decision

- Everything in the repository is in English: code, identifiers, comments, commit messages, PR text, Markdown files, logs, ADRs and UI strings.
- Turkish planning notes from the old working folder were not copied into the repository. The SRS PDF, the UI screenshots and the prototype (already in English) were kept.

## Consequences

- Team members may talk to their agents in Turkish, but the agent writes English into the repository (`docs/guides/AGENT_RULES.md` section 9).
